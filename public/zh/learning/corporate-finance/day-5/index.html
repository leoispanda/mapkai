The 92 Percent Illusion

《通过率最高的驾校》

01

开场故事或商业情境

小林准备学开车。

她在网上搜索附近的驾校，第一家广告写着：

首次考试通过率92%，连续三年本地区第一。

广告下面放着十几张照片。照片里的学员站在考试中心门口，手里拿着刚刚取得的驾照。很多评论也提到，这家驾校要求严格，但很会帮助学员准备考试。

小林很快作出决定。

“就选这家吧。通过率最高，应该最可靠。”

她的同事安娜刚好也在学车，听完后问：“你知道这个通过率是怎么算的吗？”

小林摇了摇头。

“通过的人除以参加考试的人，不就是通过率吗？”

安娜重新打开驾校的网站。

页面最上方写着92%，但在很下面的位置还有一行小字：

数据仅包括完成全部课程，并由教练安排参加首次考试的学员。

“这有什么问题？”小林问。

“可能没有问题。”安娜说，“但没有完成课程的人不在里面，教练认为还没有准备好、不允许报名考试的人也不在里面。”

小林打电话询问驾校。

接电话的人很坦率地告诉她，这家驾校对考试报名控制得非常严格。学员只有通过内部模拟测试，教练才会帮助预约正式考试。

“这样不是挺好吗？”小林说，“至少不会让学员没有准备好就去考试。”

“当然有好处。”安娜回答，“但这也意味着，92%并不代表所有报名学员的成功率。它代表的是被教练选中参加首次考试的人当中，有92%通过。”

第二天，小林又查看了另外两家驾校。

第二家的首次考试通过率只有68%。但这家驾校接受很多以前在其他地方学过、已经多次考试失败的学员，也允许学员自己决定什么时候参加考试。

第三家没有公布一个统一的通过率，而是分别列出了：

手动挡学员通过率；自动挡学员通过率；首次考试通过率；补考通过率；普通课程完成情况；强化课程完成情况。

单看最大的数字，第三家并不突出。

但是，小林至少能够知道，这些数字是在什么条件下产生的。

她开始继续比较价格。

通过率92%的驾校，基础套餐看起来并不贵，包括二十节课和一次模拟考试。不过，很多学员最后还需要额外购买十到十五节课程。周末和晚上上课需要另外收费，考试当天使用教练车辆也不包含在套餐中。

通过率68%的驾校，每节课稍贵，却没有另外收取周末费用，重新安排课程也比较灵活。

如果只比较广告上的套餐价格，第一家明显更便宜。

但是，把学员实际可能使用的课程、考试车辆和额外费用全部算进去以后，两家的差距就没有那么大了。

小林还发现，这些驾校服务的学员并不完全相同。

第一家主要提供密集课程。学员每周至少上三次课，通常希望在两三个月内参加考试。这种安排很适合时间比较自由、能够集中练习的人。

小林刚开始一份新工作，每周只能在周末上一节课。她学习速度不慢，但在复杂路口容易紧张，需要较长时间建立信心。

安娜说：“通过率最高的驾校可能确实很好，但它的课程不一定适合你的时间和学习方式。”

小林仍然没有完全放弃第一家，于是预约了一节体验课。

教练技术很好，讲解也很准确。但整节课安排得非常紧。小林刚完成一个动作，教练便要求她立刻进入下一个练习。

课程结束后，教练建议她购买三十节强化课程，并尽量在工作日安排训练。

“如果我只能每周上一节课呢？”小林问。

“进度会比较慢。”教练说，“而且我们不能保证给你固定的周末时段。现在学员很多，每位教练每天的课程都排得很满。”

小林这时才明白，过去的高通过率是在一套特定条件下形成的：

教练严格控制谁可以参加考试；学员需要保持较高的训练频率；课程安排比较紧凑；大部分学员能够配合驾校的时间；统计只包括已经完成课程并正式参加首次考试的人。

这些条件本身没有问题。

问题只是，它们和小林的情况并不完全匹配。

最后，小林选择了第三家驾校。

这家驾校的广告没有写“本地区第一”，教练也没有承诺她一定能在多少节课以后通过考试。

体验课结束后，教练只是清楚地告诉她：“按照你现在的情况，可以先每周上一节。等你对道路判断更加稳定以后，再决定是否增加训练频率。现在还不能准确预测你需要多少节课。”

半年后，小林参加了第一次考试，但没有通过。

她在一个繁忙路口判断得太慢，考官进行了干预。

小林当然很失望。

教练没有急着为她预约下一次考试，而是把考试报告和过去几个月的训练记录放在一起，找出她在复杂路况中的共同问题。

六周后，小林第二次参加考试，顺利通过。

拿到驾照那天，她没有出现在“首次考试通过”的宣传照片里。

但她并不觉得自己选择了更差的驾校。

她选择的是一个能够诚实说明条件、费用和不确定性，也适合自己学习节奏的驾校。

后来，另一位同事问她：“哪家驾校最好？”

小林没有直接说出名字。

她先问：“你以前开过车吗？想学手动挡还是自动挡？每周能上几次课？你是想尽快考试，还是更在意慢慢建立信心？”

同事笑了。

“我只是问哪家通过率最高。”

小林回答：“通过率当然要看。但你还要知道，是谁参加了考试，谁没有参加，花了多少钱，以及他们是不是和你一样的学员。”

02

决策问题

决策问题领导者应如何综合价值、风险、战略与判断？

Historical return 是已经发生的结果，但它不是 manager skill 的直接证明。就像驾校的高通过率可能受到学员基础、考试筛选、课程强度和统计方式影响，一只基金过去表现较好，也可能来自更有利的市场环境、更高的风险暴露、特定的投资风格、汇率变化、较高集中度、样本选择，或真正的 manager skill。因此，今天的任务不是根据历史排名直接选出冠军，而是先判断：比较对象是否真正可比；样本是否完整；回报是否经过风险和费用调整；差异是否来自结构、市场或经理能力；产品是否适合具体投资者。只有完成这些判断，历史表现才能被转化为专业建议。

五步知识链｜从“最高通过率”走到专业建议

先确定谁会根据比较作决定 → 再检查哪些样本没有进入结果 → 再统一比较对象和计算口径 → 再解释扣除成本与风险后的差异 → 最后判断产品适合谁。

#### 01｜先确定比较是替谁作的

基金不会脱离投资者而自动成为最好。先放入 investment objective、holding period、investor currency、liquidity need、risk tolerance、实际可购买范围及税务限制；随后才统一 asset class、fund category、share class、active/passive、地区和策略。Decision set 不同，“哪只最好”就没有意义。

#### 02｜比较表现前，检查哪些样本没有被看见

关闭、合并、改名、停售或从数据库移除的基金，可能让留下来的平均表现显得更好，这就是 survivorship bias。检查样本来源、纳入与排除规则、关闭基金是否保留、backfill、起始时间和期间是否避开困难年份。先修复比较地基，统计才有意义。

#### 03｜把回报放到同一把风险尺子上

更高回报可能来自 equity 或 interest-rate risk、地区、style、factor、currency、concentration 或 liquidity exposure，而不只是经理能力。Benchmark 应匹配 asset class、地区、style、factor 和可投资范围；period 要公平，跨币种还必须说明 local、investor 或 hedged return。统一后才能分辨能力、环境、风格或汇率。

#### 04｜看投资者真正拿到的净结果并拆开来源

考虑 expense ratio、sales load、transaction cost、tax、liquidity cost 和 turnover，也看 volatility、drawdown、concentration、capacity constraint。小规模策略的成功不一定能随资产扩大复制。行业结构、distribution channel、pension system、监管和投资习惯能帮助解释费用和竞争，但相关不等于因果。

#### 05｜把分析翻译成有边界的 suitability 建议

Recommendation 不宣布永久冠军，而是说明为什么适合这位投资者、哪些证据支持、要承担什么风险、哪些 assumptions 未验证、数据有哪些 limitations，以及什么变化触发重新评估。最终推荐的是产品风险、回报和限制与投资者目标、期限、承受能力之间的匹配。
