# MapKAI 新版题库编写约定

版本：v2-2026-10-03。依据：docs/mapkai-question-bank-principles.zh.md 的 Principles v3。

本轮生成完整双语候选：Explore 20 题（8 调查、12 任务，每题四项及跳过）和 Map 132 题（11 领域每科 12 题，每题三项、唯一答案、逐题解析）。用途为一般成人和进阶学生的知识探索和练习。网站运行题库另行接入；本文件与候选不改变网站、地图阈值或历史进度。

## 知识题分工与内容

- 00 至 03：48 题，通用学习、教育、艺术人文、社会科学。
- 04 至 07：48 题，商业法律、自然科学数学统计、计算技术、工程建造。
- 08 至 10：36 题，农业生态、健康医学、服务运输。

先在自己的 editorial 文件中建立 12 题每科的概念与操作蓝图，再写题。参照当前旧库和逐题复审，有效的目标与情境优先修订；失效、重复、猜动机或口号题换成可操作的小任务。不要机械换人物或给正确项补成长篇机制句。概念辨认可以保留，但一科不能全是辨认或泛化系统格言。

## 文件与字段

知识题各分工写两个 JSON 数组：`parts/map-00-03.json` / `parts/editorial-00-03.json`，其余以 `04-07`、`08-10` 替换。

题目字段：`id`、`subject`、`en`、`zh`。两种语言各有 `question`、三个字符串 `options`、精确匹配一个选项的 `answer`、不套品牌模板的 `explanation`。

保留目标的修订沿用旧 `00-q1` 等 ID；改变目标的替换用 `00-v2-q01` 等新 ID。每科仍对应旧 q1 至 q12 的十二个修订位置；在编辑记录注明 `sourceId`。题库版本隔离旧新记录；复用 ID 不意味着允许混用旧题进度。

编辑记录每题包括：`id`、`sourceId`、`changeType`、`revisionReason`、`concept`、`objective`、`cognitiveOperation`、`context`、`difficultyEstimate`、`difficultyReason`、三个稳定 `optionIds`、`answerOptionId`、两个 `distractors`（`optionId / error / whyNot`）、`answerEvidence`、`factSources`（`url / title / checkedAt / supports`）、`keepLogicalOrder`、`status`。蓝图先写目标、操作和情境，生成后补齐判定与记录。作者阶段状态为 `writer-reviewed / awaiting-independent-review`，不是实测通过。

`keepLogicalOrder` 仅用于需要数值、时间或阶段顺序的选项；其他题会在合并时按稳定标识安排显示顺序，中英同步，不按正确位置循环。不能只凭选项长度、语气、题干关键词或绝对词猜中。检查正确项独占最长时是否确有形式暗示，不能靠给错误项补废话消除指标。

## 事实与独立复审

题干必须给出决定答案的条件，不靠解析补事实。错误项是可解释的真实误解，在本题条件下不能同样满足问法。数学可直接核算；现实中的医学、安全、法律、金融、工程及生态机制按必要程度核对官方或原始来源，记核查日期 2026-10-03，不虚构引用。可使用明示的虚构表格、运行规则和实验数据，题干自足；不把它包装成真实研究，不用虚构规则掩盖本领域基础事实。

不生成个人用药、法律裁决、投资买卖或安全操作指令。健康题可考已给材料的风险辨认、统计证据、信息来源、预防与卫生等基础判断；保留相应事实边界。不同学科仍有真实学科考点，不能全部换成“哪个信息来源更好”。

每题中文英文任务相同、条件等量；选项同层级、相近详略。解析解释题干证据如何支持答案及必要的混淆处，篇幅按题意决定。原题合理就局部修，不要求每题强行升级为复杂案例。

合并后换作者做独立复审：先从不带答案的数据解题，再核对答案与理由，并逐题记录问题。未解决的歧义、事实错误或形式暗示须修正后交付；真实用户试答另有状态，不因没有数据阻止候选生成。
