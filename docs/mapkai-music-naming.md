# Music display names

Show the song name in the active player, shared dock and system playback metadata. Keep the persistent catalogue number as a separate library label; subject and concept remain available for filtering.

Use `Song Name (Draft 1)`, `Song Name (Draft 2)`, etc. for versions of the same song, ordered by their existing persistent catalogue numbers. The owner-approved current `Your Turn` recording (064) uses only `Your Turn`; 061–063 are Draft 1–3. Other existing multi-version groups use Draft numbers throughout. Remove redundant standalone `(Original Version)` suffixes.

The public naming table applies only to exact existing ID/title pairs. It preserves the original stored metadata, recording ID, audio bytes, lyric text, timing, statistics and catalogue order. Version-history descriptions are omitted from the four Your Turn entries and film cards. The checked-in catalogue uses the new public titles. New publications should follow these display names without introducing ASML, Philips or genre-based version suffixes.

Music videos use the same simple approach: the current film is `Your Turn`, with the two earlier visual versions labelled Draft 1 and Draft 2. Their media objects and checksums are unchanged.
